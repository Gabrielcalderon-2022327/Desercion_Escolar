# 🏫 Sistema de Gestión de Deserción Escolar

## 📃 Descripción
Este programa de gestión está dirigido a las instituciones educativas de Guatemala para llevar un control riguroso sobre el rendimiento académico de cada estudiante. El objetivo principal es identificar alertas tempranas y evitar que los alumnos abandonen sus estudios a mitad del ciclo escolar por situaciones externas a lo académico.

El proyecto fue desarrollado bajo el marco de trabajo **SCRUM**, asegurando entregas iterativas y un enfoque centrado en las necesidades del sector educativo guatemalteco.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Java JDK 21
*   **Base de Datos:** MySQL 8.0.44
*   **Framework:** Spring Boot 4.0.2
*   **Interfaz Web:** HTML5, CSS3 y JavaScript (Fetch API)
*   **Estilos:** Bootstrap para un diseño moderno y ágil

## ✨ Características Principales
*   **🟡 Interfaz Responsiva:** La aplicación está optimizada para adaptarse automáticamente a diferentes tamaños de pantalla (móviles, tabletas y computadoras).
*   **🟡 Gestión de Alertas:** Sistema de monitoreo para identificar estudiantes en riesgo de deserción mediante el análisis de su rendimiento.
*   **🟡 Panel de Control (CRUD):** Módulos completos para la creación, lectura, actualización y eliminación de registros de estudiantes y docentes.

## 🚀 Instalación y Configuración

1. **Clonar el repositorio:**
   * Crea un carpeta local y luego usa el siguiente comando git
   ```bash
   git clone [https://github.com/Gabrielcalderon-2022327/Proyecto-Bimestre-I.git)
   
2.  **Configuración de entorno:**
   * Asegúrate de tener instalado Java JDK 21 y MySQL.
   * Crea una base de datos local en MySQL.
   * Modifica el archivo src/main/resources/application.properties con tu usuario y contraseña de la base de datos.
3. **Ejecutar la aplicación:**
   * Ejecutarlo desde tu IDE (IntelliJ IDEA o NetBeans).
   * Cuando termine el proceso debera aparece "API Funcionando".
